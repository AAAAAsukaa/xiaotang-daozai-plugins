# 便签本测试

用启用了 `sdk-js` 的岛仔，在本目录执行以下命令。`$daozai` 指向验收版 `daozai.exe`。

```powershell
& $daozai --plugin-test "$PWD\plugin.json"
Get-ChildItem .\fixtures\*.json | ForEach-Object {
    & $daozai --plugin-test "$PWD\plugin.json" --input $_.FullName
    if ($LASTEXITCODE -ne 0) { throw "验收失败：$($_.Name)" }
}
node --test fixtures/test.cjs
```

| 用例 | 预期 |
| --- | --- |
| `empty` | 显示「还没有便签」，常驻为空 |
| `normal` | 显示 3 条便签，常驻最新一张 |
| `specified` | 常驻「会议室 B 改到 3 楼」 |
| `rotate` | 常驻画布按置顶顺序每 8 秒轮换 |
| `search` | 只显示匹配「会议」的便签 |
| `pending-undo` | 显示带划线的「会议室 B 改到 3 楼」和撤销按钮 |
| `completed` | 待撤销窗口结束后归入已完成列表 |
| `expired` | 清理完成满 30 天的便签 |
| `editor-long` | 全宽编辑框载入完整多行便签，滚轮可查看末行 |
| `pinned-long` | 两条多行便签进入常驻轮播，正文滚动时能看到各自的「收尾标记」 |

`fixtures/test.cjs` 覆盖多行添加与编辑、复制、删除、手动完成与 3 秒内撤销、置顶排序、配色、三种常驻模式与取消常驻、搜索、专注事件去重、千条分页与滚动、存储容量及三种截图状态。`--plugin-test` 只调 `refresh`，交互和事件由测试脚本直接调用入口。常驻宽度自适应需要支持 `fit_width` 的宿主。正常、撤销与空状态的截图分别使用 `normal`、`pending-undo`、`empty`，预览时钟取用例的 `now`。

在「设置 → 插件 → 已安装 → 开发者工具」选 `plugin.json` 试装。启用后切到便签本详情。在左下输入正文，点「＋」添加。在右上输入关键词，按 Enter 或点放大镜筛选，清空后提交可恢复列表。点右侧列表切换便签。点纸卡右上角的图钉切换置顶，底部常驻按钮和列表用同一蓝色指示，蓝色状态下再点可取消常驻。点铅笔进入编辑页，选择色块后立即更新配色，正文用「保存」提交。置顶便签可用「上移」「下移」调整顺序。手动完成时只在列表底部显示三秒撤销入口。在设置的常驻位中启用便签本，尝试三种常驻模式。结束一次专注后核对新增红色来源便签的正文。

快捷录入按 Enter 添加。编辑和粘贴使用多行表单，Enter 换行，Ctrl+Enter 提交。编辑长便签时，把鼠标移到正文内滚动。把鼠标停在纸卡底部的四个图标上可查看操作名称。「粘贴」默认用蓝色标记这条便签。常驻选择记录在插件私有存储。在「已安装」的「···」菜单可导出或导入数据。
