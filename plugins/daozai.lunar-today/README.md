# 今日农历

在岛仔的「待办与置物」查看当天农历。节气当天会在农历日期后显示节气名，例如「农历十月十四 · 小雪」。

安装后到「我的插件」启用。按电脑的本地日期刷新，支持公历 1901 至 2100 年，可离线使用。

历法数据由 [lunar-javascript](https://github.com/6tail/lunar-javascript/tree/5c92e62c904ba5cc0b62f032796aeef433702268) 生成，采用 MIT 许可证。样例按[香港天文台公历与农历转换表](https://www.hko.gov.hk/tc/gts/time/conversion.htm)核对。
