# 岛仔官方插件风格

官方插件的封面、名称和说明按本页统一。「官方」标识以 [`.github/official-plugins.json`](../.github/official-plugins.json) 的登记为准。社区作者可以参照本页，让插件在集市里和官方插件风格一致；投稿审核仍以[作者投稿指南](author-submission.md)的要求为准。

## 封面

封面展示插件装好后在岛仔里的样子，让用户一眼看出它会带来什么。

- 尺寸为 960 × 540 的 PNG，最大 256 KiB。
- 背景使用浅色底和白色细网格。网格间距约 36 px，线宽 2 px，透明度约 55%。底色按插件归属选择：

  | 归属 `owner` | 底色 | 示例 |
  |---|---|---|
  | `tasks` 待办与置物 | 浅青 `#E1F5EE` | 今日农历 |
  | `pages` 页面与导航 | 浅紫 `#EEEDFE` | 页面快捷切换 |
  | `wireless` 无线设备 | 浅蓝 `#E6F1FB` | 无线设备兼容 |
  | 其他 | 浅珊瑚 `#FAECE7` | |

- 画面正中只放一个主体：插件生效后的真实卡片、导航条或设备状态。主体按岛仔实际界面绘制，可适当放大，四周至少留出画面 15% 的空白，避免 16:9 居中裁切时被切掉。
- 封面里不写插件名、宣传语或版本号。集市卡片已在封面下方显示名称，缩略图里的小字也看不清。主体里属于界面本身的文字可以保留，例如卡片上的「十月十四」。
- 不加装饰线、角标、多层阴影和渐变。主体可以用一层柔和投影和底板区分。
- 停用后的去色淡化由岛仔统一处理，封面只提供正常状态。

## 名称

- 使用 2 至 6 个字的中文功能名，说清插件做什么，例如「今日农历」「页面快捷切换」「无线设备兼容」。
- 名称不带「包」「插件」「助手」「Pro」等后缀，也不带「岛仔」前缀。官方身份由作者和官方标识体现。
- 第三方产品名保留官方写法，例如「DeepSeek 余额」。
- 官方插件 ID 使用 `daozai.<英文短名>`，短名用小写英文和连字符，与中文名称对应，例如 `daozai.page-shortcuts`。

## 说明

`README.md` 的标题与插件名称一致，正文按下面三段组织。

1. **用途**：第一句写用户能得到什么，格式为「在〈页面〉〈做什么〉」，30 字以内，例如「在待办页查看当天农历和节气」。需要时再补一两句具体表现。
2. **启用**：统一写「安装后在「设置 → 插件 → 已安装」启用」，再说明停用或卸载后岛仔的表现，以及能否离线使用。
3. **来源与范围**：数据来源、兼容型号、支持范围和第三方许可放在最后。具体型号、接口和复现细节写在这一段，不放进第一句。

界面名称用「」包裹，路径层级用「 → 」连接，和岛仔设置里的文字保持一致。
